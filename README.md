# Frontend-разработчик — цифровые продукты

Тёмное редакционное портфолио frontend-разработчика, собранное на React, TypeScript, Tailwind CSS и lucide-react.

## Что внутри

- Адаптивный первый экран с локальным видео-фоном и плавным направлением видео вперёд–назад.
- Шесть концептуальных кейсов на темы брендинга, интерфейсов и цифровых продуктов.
- Stacking-scroll для кейсов и marquee-панель инструментов с Python, React, Git и другими символами.
- Прямое описание опыта, стека и форматов задач без вымышленных отзывов и лишних цитат.
- Фильтрация проектов и доступное модальное окно с деталями кейса.
- Русская версия интерфейса без контактных данных и без вымышленных отзывов.

## Запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```
